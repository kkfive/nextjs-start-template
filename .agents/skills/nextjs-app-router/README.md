# Next.js App Router Skill

Next.js App Router - Server Components、流式渲染、并行路由、数据获取、性能优化、Metadata。

## 使用场景

- 在 `apps/client`、`apps/admin` 等 Next.js app 下构建页面/路由
- 实现 SSR/SSG
- 优化 React Server Components
- 配置路由和数据获取
- 性能优化和 SEO
- 多 app 场景下的 BFF 与缓存策略

## 调用方式

```bash
/nextjs-app-router
```

## 覆盖范围

- Server/Client Components 决策
- 文件约定（layout、page、loading、error）
- 数据获取和缓存策略
- 路由模式（并行路由、拦截路由）
- API Routes (Route Handlers)
- 性能优化（Image、Bundle）
- Metadata 配置
- 项目结构推荐
